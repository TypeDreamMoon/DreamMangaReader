# 小说阅读器体验重构设计

日期：2026-08-07

状态：已确认，待实施计划
目标平台：Android、Windows

## 1. 背景

当前小说阅读器使用 `InAppWebView` 排版整章内容，再通过 CSS 多栏和浏览器
`scrollTo(..., behavior: 'smooth')` 完成分页。触摸手势只在松手后按固定 50 px
阈值触发上一页或下一页，没有独立的跟手、完成、回弹和连续翻页状态。

现有方案能够显示 TXT、EPUB、源站 HTML、图片与注音，但存在以下体验问题：

- 页面不跟手，翻页节奏由 WebView 决定，Android 与 Windows 表现不一致；
- 翻页时没有稳定的上一页、当前页、下一页缓存，章节边界容易等待或闪白；
- 排版仅提供字号、行高、段距和左右边距，缺少首行缩进、上下边距等常用能力；
- 背景只有四套纯色主题，没有纸张纹理、自定义背景和主题配置；
- 没有书签、全文搜索、划线批注和笔记；
- 阅读位置主要依赖比例与可见块，重排后的恢复精度仍需提高。

本设计参考掌阅 8.7.7 的可观察交互和资源结构，包括独立翻页控制层、三页绘制、
可配置动画时间、五种翻页模式、字体与阅读距离设置。掌阅的核心翻页计算位于原生库，
实施时只通过正常操作和录屏测量行为，不复制其代码、字体、图片、纹理或其他素材。

## 2. 目标

- 仿真翻页作为默认模式，支持全屏跟手拖动、完成翻页和自然回弹；
- 一次提供仿真、覆盖、平移、无动画、上下滑动五种模式；
- Android 与 Windows 共用翻页状态和排版语义，分别适配触摸、鼠标、滚轮和键盘；
- 保留现有 TXT、EPUB、HTML、图片、注音与离线缓存兼容性；
- 增加完整中文正文排版、内置/导入字体、纸张/自定义背景；
- 增加书签、全文搜索、复制、划线批注和笔记；
- 设置改变、横竖屏切换和正文更新后仍尽量恢复到同一段正文；
- 阅读进度、书签和批注支持本地持久化、便携备份与现有云同步体系。

## 3. 非目标

- 本阶段不提供词典、在线释义和文本朗读；
- 不复制或分发掌阅的专有代码、字体、纸张纹理和动画资源；
- 不把任何来源的小说正文、页面纹理或全文搜索索引上传到云端；
- 不在本阶段为用户自有内容增加“同步正文”能力；
- 不改变小说源脚本协议和正文获取权限边界。

## 4. 总体架构

### 4.1 NovelContentEngine

负责 TXT、EPUB、源站 HTML、图片缓存和内容清洗，输出带稳定块标识的规范化文档。
该模块不处理输入手势和翻页动画，继续复用现有导入器、清洗器和缓存层。

### 4.2 NovelPaginationEngine

根据视口、屏幕方向、字体、字号、行距、段距、页边距和主题完成分页。WebView 仍负责
复杂 HTML 与 EPUB 的排版兼容，但不再直接承担用户可见的翻页动画。

分页结果至少包含：

- 页索引、页数和所属章节；
- 页面对应的块 ID、字符范围和全章比例；
- 用于恢复位置的正文引用、前后文校验与布局版本；
- 当前页面的显示纹理以及可选的无障碍文本信息。

排版设置改变后，先捕获语义定位，再重排并恢复到同一块和字符附近；仅在语义定位失败时
回退到章节比例。

### 4.3 NovelPageCache

常态缓存上一页、当前页和下一页的页面纹理。接近章节首尾时提前获取相邻章节内容并生成
边界页。缓存键包含文档版本、章节、页索引、视口和排版配置哈希。

缓存采用自适应预算：内存充足时保留三页和相邻章节边界页，内存压力下先释放远端页面，
再缩减为当前页与目标页，任何时候都不先清除当前可见页。

### 4.4 NovelPageTurnController

统一管理以下状态：

1. `idle`：等待输入；
2. `tracking`：检测手势方向，尚未锁定翻页；
3. `dragging`：页面跟随手指或鼠标；
4. `settling`：松手后完成翻页或回弹；
5. `committing`：更新当前页、定位和缓存窗口；
6. `waitingForPage`：目标页尚未准备好，保留当前页并显示边缘加载状态。

所有平台输入先归一化为同一套开始、更新、结束、取消和离散翻页命令。菜单、文字选择、
笔记编辑和系统中断能够显式取消或暂停翻页状态。

### 4.5 NovelPageTurnSurface

负责五种模式的绘制，不读取书籍业务状态：

- 仿真：页面纹理卷曲、背面明暗、接触阴影和完成/回弹；
- 覆盖：当前页随手势移出并露出目标页；
- 平移：当前页和目标页同步平移；
- 无动画：收到有效命令后立即提交目标页；
- 上下滑动：使用自然惯性滚动，不套用横向仿真的提交阈值。

仿真优先使用 Flutter GPU 绘制。在不支持目标着色能力或持续渲染失败时，只针对当前会话
降级为覆盖模式，并保留恢复入口和错误提示。

## 5. 翻页节奏与输入

### 5.1 默认交互

- 仿真翻页为默认模式；
- 正文任意非交互区域均可开始横向拖动，页面实时跟手；
- 左侧 25% 点击上一页，中间 50% 切换工具栏，右侧 25% 点击下一页；
- 提供“左右两侧均为下一页”的单手设置；
- 文字链接、选择柄、按钮和笔记面板不触发翻页；
- Windows 鼠标拖动与触摸使用相同状态，滚轮每次只提交一页并节流；
- Windows 支持方向键、PageUp/PageDown 翻页和 Esc 关闭菜单。

### 5.2 初始参数与掌阅测量

初始实现使用约 10 逻辑像素的触摸方向判定、约 28% 屏宽的距离提交阈值，以及速度提交
阈值。点击自动翻页约 260 ms，松手完成约 140-280 ms，回弹约 180 ms。最终值不直接
固化为上述估算，而按以下方式校准：

1. 在同一 Android 设备上向掌阅和 DreamMangaReader 导入同一本 TXT；
2. 录制慢拖、快速甩动、短距离回弹、左右点击和连续翻页；
3. 按帧测量开始响应、松手到结束、回弹和连续输入间隔；
4. 在窄屏、宽屏、60 Hz 与高刷新率设备上复测；
5. 将阈值换算为视口比例和逻辑像素，避免只适配单一分辨率。

松手动画时长根据剩余距离与释放速度计算，使用前段响应快、末段柔和减速的曲线，不采用
匀速。连续点击最多预接收下一次命令，防止动画队列无限堆积。

## 6. 排版、字体与背景

### 6.1 快速设置

- 字号加减；
- 字体选择；
- 背景选择；
- 应用内亮度；
- 翻页模式。

### 6.2 高级排版

- 行间距、段间距；
- 左右边距、上边距、下边距；
- 首行缩进；
- 左对齐与两端对齐；
- 恢复默认。

设置实时预览，但每次重新分页都通过语义定位恢复正文位置。阅读文字的字符间距保持为 0，
不增加可能破坏中日韩标点和 EPUB 样式的负字距选项。

### 6.3 字体

项目内置数套具有合法分发许可、适合中文正文与轻小说的字体，同时支持导入本地 TTF/OTF。
导入流程校验格式、字体名称、重复项和基本可用性，将文件复制到应用数据目录。字体损坏、
缺失或无法加载时自动回退到内置正文字体，不能出现整页空白。

### 6.4 背景与主题

内置纯白、护眼、深色、纯黑和多套项目自有的低对比度纸张纹理。用户可导入图片并选择
裁剪、平铺或填充，以及纹理强度。系统根据背景估算可读文字颜色，用户仍可手动覆盖。

每套主题保存背景、文字颜色、应用内亮度和字体搭配，其他排版参数保持用户全局选择。
自定义字体和背景只保存在本机；同步时只传内置资源 ID 和可移植设置。

Android 支持跟随系统亮度、应用内亮度和保持常亮。Windows 不修改系统全局亮度，只调节
阅读画布表现。

## 7. 阅读界面

正常状态只显示正文和用户选择开启的章节名、页码/总页数、全书进度、时间与电量。
工具栏覆盖在阅读画布之上，显示和隐藏不触发正文重排。

- 顶栏：返回、书名/章节名、书签、更多；
- 底栏：上一章、全书进度、下一章、目录、搜索、主题、排版；
- Android 使用底部面板，Windows 宽屏使用右侧面板；
- 工具栏使用短距离位移和淡入淡出，不使用夸张缩放；
- 自动隐藏时间沿用用户设置，操作面板时暂停倒计时；
- 横屏和窄屏按可用空间收纳次要命令，正文与控件不重叠。

## 8. 书签、选择、批注与笔记

### 8.1 文本选择

长按或鼠标拖动进入选择状态，提供复制、划线、添加笔记和本书搜索。选择状态暂停翻页，
选择结束后恢复。文本选择保存章节 ID、稳定字符范围、选中文本和短前后文，不保存页码。

### 8.2 书签

书签记录作品键、章节、语义定位、正文短摘要、创建时间和修改时间。目录面板包含“目录、
书签、笔记”三个标签。点击书签恢复到正文位置，无法精确重定位时显示最接近位置和提示。

### 8.3 划线和笔记

划线提供数种克制颜色。点击已有划线可查看、编辑或删除笔记。正文更新后先按字符定位，
再用选中文本与短前后文重新查找。仍无法匹配时保留为“待重新定位”，不得静默删除。

本阶段不提供词典和朗读入口。

## 9. 全文搜索

- 本地 TXT、EPUB 与已下载小说可搜索全部已有章节；
- 未下载网络小说默认搜索缓存章节；
- 用户选择“搜索全书”时按源能力逐章获取纯文本索引，并显示进度与取消；
- 索引按章节增量生成，只保存在本地，正文更新后仅重建变化章节；
- 搜索结果显示章节名与命中上下文，点击后语义定位并临时高亮；
- 搜索在后台 isolate 中逐章执行，能够边索引边返回结果，不阻塞翻页。

搜索缓存不是书籍备份，不进入账号同步、WebDAV 或便携备份。

## 10. 数据与同步

阅读进度继续兼容 `NovelLocator`，新增独立的阅读数据存储，按作品保存书签、批注、笔记与
作品级排版覆盖。数据项具有稳定 ID、创建时间、更新时间和删除墓碑。

同步规则：

- 不整本覆盖，按书签或批注 ID 合并；
- 两端修改不同数据时取并集；
- 同一数据冲突时采用最后修改版本；
- 删除墓碑参与合并，防止另一设备恢复已删除项；
- 本地作品以内容指纹识别，网络作品以源 ID、作品 ID 和规范化标题识别；
- 自定义字体、背景、页面纹理、搜索索引和小说正文不进入同步。

便携备份可包含设置、定位、书签、划线与用户笔记，但不得包含完整章节、小说文件或设备
绝对路径。为批注重定位保存的原文仅限选中文本和短前后文。

## 11. 生命周期与异常恢复

- 只在翻页提交完成后保存新位置，拖动中断不误记到目标页；
- 进度允许短暂防抖，进入后台、关闭页面和应用退出时立即刷新；
- 目标页未准备好时保留当前页，显示边缘加载状态并允许取消；
- 页面纹理失败时重试，持续失败才会话级降级到覆盖模式；
- 损坏字体和背景分别回退内置字体与主题底色；
- 横竖屏切换、窗口缩放和排版修改先取消当前手势，再重排并恢复语义定位；
- 文档版本、视口或排版配置变化时使旧页面纹理失效，不复用错误分页。

## 12. 性能与验收

### 12.1 性能目标

- 已缓存页面收到输入后下一帧开始运动；
- 60 Hz 设备持续翻页以稳定 60 fps 为最低目标；
- 手指拖动期间不进行同步磁盘写入、网络请求或正文重新排版；
- 页面纹理缓存具有明确内存预算并在低内存回调中主动缩减；
- 章节边界已预取时不显示整页加载状态。

### 12.2 测试材料

- `雪中悍刀行.txt`；
- `我有一座恐怖屋.txt`；
- `诡秘之主.txt`；
- `刀剑神域 进击篇09.epub`。

这些文件只用于本地兼容性验证，不复制到仓库。

### 12.3 自动验证

- 翻页状态机的距离、速度、取消、回弹和连续输入测试；
- 分页缓存窗口、章节边界和内存收缩测试；
- 修改设置、旋转屏幕后的语义定位测试；
- 书签、批注、删除墓碑和同步冲突测试；
- 中文搜索、取消索引与增量重建测试；
- 字体损坏、背景丢失、纹理失败和目标页加载失败测试；
- 现有 TXT、EPUB、清洗、缓存和小说同步测试保持通过。

### 12.4 手动验证

- Android：触摸、系统中断、后台恢复、横竖屏和不同刷新率；
- Windows：鼠标拖动、触控、滚轮、键盘、窗口缩放和高 DPI；
- 五种翻页模式逐项检查正文不闪白、不跳页、不丢进度；
- 与掌阅同书同设备录屏对比慢拖、快甩、回弹、点击和连续翻页节奏；
- 检查纸张背景、深色主题、长段落、图片、注音和特殊符号。

## 13. 实施边界

本功能在作者最新 `upstream/main` 基础上开发。优先建立分页、缓存和翻页状态机，再接入
排版与主题，最后接入书签、批注、搜索和同步。每个模块通过接口隔离，避免继续扩大
`novel_reader_page.dart` 与 WebView 桥接脚本的职责。
