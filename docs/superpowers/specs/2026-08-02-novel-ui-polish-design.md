# 小说界面与阅读排版修正设计

## 状态

- 日期：2026-08-02
- 基线：`upstream/main@6b8269a`（v1.4.0）
- 目标分支：`codex/novel-ui-polish`
- 状态：设计已确认，等待用户复核书面规格

## 背景

v1.4.0 已合并小说阅读、TXT/EPUB 导入、在线小说源、独立书架、下载与同步功能，也完成了书架颜色和外壳的第一轮修正。目前仍有四类问题：

1. 源健康检测只按漫画接口构建源，`meta.kind = novel` 的起点源会被误报为协议错误。
2. 小说发现和搜索使用独立列表，未遵守作者要求的漫画同款瀑布流、网格和列表布局。
3. 小说详情页与漫画详情页的视觉层级、间距和操作区不一致。
4. 阅读页在宽屏上正文过宽，工具栏和进度层级不符合成熟小说阅读器的使用习惯。

本设计参考 LightNovelReader 的沉浸控制、ReadAny 的即时排版设置、Readest 的阅读设置组织方式，以及轻阅、QQ 阅读、微信读书一类产品的常见交互。参考只用于确定布局与交互，不复制第三方实现。

## 目标

- 修复小说源健康检测，不影响漫画和番剧检测。
- 小说发现、搜索列表与漫画使用同一套布局系统。
- 小说详情页复用漫画详情页的主要视觉结构。
- 保留现有 TXT、EPUB、在线章节、缓存、下载、进度和云同步能力。
- 将阅读页改成适合 Windows 与 Android 的沉浸式单页阅读界面。
- 让字体、字号、行高、段距、页边距、主题和工具栏自动隐藏均可调整并全局保存。

## 非目标

本次不实现以下功能：

- TTS、批注、划线、书签和亮度控制。
- LOFTER 源及其登录、Cookie 或接口逆向。
- 双页排版和每本书独立排版设置。
- 替换现有 WebView 阅读内核。
- 本地 Windows 或 Android 平台打包。

## 总体方案

采用定向复用方案，不先重构整个内容 UI 框架：

- 列表层复用 `FeedLayout` 和 `FeedView` 的漫画布局规则。
- 详情层复用漫画详情页的头部、元数据、简介和收藏操作模式。
- 阅读层保留 `NovelDocumentController`、`NovelDocumentView` 和现有安全 HTML 流程，重构外部控制层与正文 CSS。
- 小说专有部分仅保留小说卡片字段、紧凑章节目录和文字排版设置。

这样可以满足作者对一致性的要求，同时将漫画回归风险限制在共享组件适配边界内。

## 源健康检测

健康检测必须先读取 `SourceMeta.kind`：

- `manga`、`anime`：继续使用 `buildSource`，调用漫画协议的 `getDiscovery(1)`。
- `novel`：使用 `buildNovelSource`，调用小说协议的 `getDiscovery(1)`。
- 其他值：报告明确的源类型协议错误。

检测日志保留源名、ID、传输方式、超时、耗时和结果。错误需要区分超时、网络异常、脚本协议异常和不支持的类型，不能再把可用小说源显示为“expected manga or anime”。

## 小说列表

### 布局

小说发现和搜索必须跟随漫画当前的全局 `FeedLayout`：

- `masonry`：复用漫画瀑布流尺寸和间距。
- `grid`：复用漫画规则网格和封面比例。
- `list`：复用漫画横向列表行结构。

小说不得维护第二套布局枚举或独立布局设置。切换漫画布局后，小说列表应立即使用同一选择。

### 卡片内容

小说卡片在共享布局内提供以下字段：

- 封面和标题。
- 作者。
- 来源名称。
- 连载状态或简短说明；空间不足时按漫画卡片的截断规则处理。

卡片的加载骨架、错误状态、空状态、点击反馈和响应式断点与漫画一致。不得改成 LOFTER 风格的信息流。

## 小说详情页

详情页顶部复用漫画详情页的视觉结构：

- 返回与页面操作区。
- 封面、标题、作者、来源、状态和标签。
- 简介的展开/收起。
- 收藏、继续阅读/开始阅读和切换来源操作。

章节区保留小说专用的紧凑列表，不照搬漫画章节网格。列表必须：

- 使用惰性构建以支持长目录。
- 显示章节序号与标题。
- 支持卷标题分组。
- 高亮当前阅读章节，并可快速滚动定位。
- 在 Windows 宽屏上使用受约束内容宽度，避免每行贯穿整个窗口。

## 阅读器布局

### 默认模式

- 首次使用默认 `paged` 左右分页。
- 保留 `scroll` 上下滚动，并记住用户最后选择。
- Windows 宽屏始终使用居中单页，不启用自动双页。

### 正文排版

- Windows 正文最大可读宽度约 `760px`，剩余空间作为稳定留白。
- Android 使用约 `20px` 的基础水平页边距，并叠加用户设置。
- 默认字号 `18px`、行高 `1.7`、段距 `10px`。
- 保留白色、深色、纯黑和护眼色主题。
- 正文字间距固定为 `0`，长单词和链接允许安全换行。
- 图片受正文宽度约束，不能撑破页面。

TXT、EPUB 和在线 HTML 继续经过现有清理、CSP 与本地资源缓存流程。排版变化不得放开 WebView 网络访问。

## 沉浸工具栏

阅读器加载完成后默认隐藏控制层：

- 左侧 25%：上一页。
- 中间 50%：显示或隐藏控制层。
- 右侧 25%：下一页。

顶部工具栏仅包含返回、书名和当前章节。底部工具栏包含：

- 目录入口。
- 整本书进度条及百分比/目标章节预览。
- 主题入口。
- 字体与排版设置入口。

工具栏自动隐藏是全局阅读设置，位于点击正文后出现的底部排版设置中：

- 使用 `0-10 秒`、步长 `1 秒`的数值滑块。
- 默认 `4 秒`。
- `0 秒`表示关闭自动隐藏。
- 打开目录、主题或设置面板时暂停计时。
- 用户继续操作控制层时重新计时。
- 完成翻页后回到纯正文状态。

Android 的目录和设置使用底部抽屉；Windows 使用宽度受限的侧边面板。面板不使用嵌套卡片。

## 输入方式

### Windows

- `Left`、`Page Up`：上一页。
- `Right`、`Page Down`、`Space`：下一页。
- 鼠标滚轮在分页模式下翻页，在滚动模式下自然滚动。
- `Escape` 优先关闭目录/设置或隐藏控制层。

### Android

- 支持左右点击区。
- 分页模式支持横向滑动。
- 保留音量键翻页能力。

输入事件发生在目录、设置或可交互正文元素上时，不得穿透触发翻页。

## 排版设置

排版设置全局作用于所有小说并即时生效、自动保存：

- 分页/滚动模式：分段选择。
- 字体：系统、衬线、无衬线、等宽。
- 字号：`A-`、当前值、`A+`，保留合理上下限。
- 行高、段距、页边距：数值滑块。
- 主题：颜色样本选择。
- 保持屏幕常亮：开关。
- 工具栏自动隐藏时长：`0-10 秒`滑块。

修改设置时必须捕获当前位置，重新排版后恢复到同一文本块附近，不能跳回章节开头。

## 整书进度

整书进度采用当前章节索引与章内比例组合：

`progress = (chapterIndex + chapterFraction) / chapterCount`

该值适用于在线章节无法预先得知字数的情况。交互规则：

- 拖动时只更新百分比和目标章节预览，不连续发起章节请求。
- 松开后计算目标章节与章内比例，再执行一次跳转。
- 加载失败时恢复上一次成功位置，不保存失败目标。
- 成功后继续使用现有阅读进度和云同步数据流。

## LOFTER 兼容边界

未来制作 LOFTER 源时，建议映射为：

- 合集或系列 -> `Novel`。
- 图文文章 -> `NovelChapter` 和 HTML `NovelDocument`。
- 作者、标签、来源、更新时间 -> 详情元数据。

本次 UI 不加入 LOFTER 专用字段，但不得假定章节内容只有纯文本。登录、Cookie、接口和站点限制留在未来的来源实现中。

## 错误与状态

- 源检测错误必须包含可理解的分类和原始摘要。
- 章节加载失败时保留当前目录与重试入口。
- 进度跳转失败不能覆盖已保存进度。
- 空目录、无封面、无作者和无简介均有稳定降级显示。
- 超长标题、作者和章节名必须截断或换行，不得与操作按钮重叠。

## 测试与验收

### 自动测试

- 起点小说源可通过健康检测，且实际调用小说协议。
- 漫画、番剧和未知类型的检测行为保持正确。
- 小说列表在 `masonry`、`grid`、`list` 下使用共享布局。
- Windows 和 Android 代表宽度下不存在溢出。
- 阅读器默认隐藏工具栏，三个点击区行为正确。
- 自动隐藏时长可保存，`0` 可关闭，面板打开时暂停。
- 整书进度计算、预览、单次跳转和失败回滚正确。
- 排版设置即时生效并保持阅读位置。
- 现有 TXT、EPUB、下载、阅读进度和同步测试保持通过。

### 工程检查

- 运行 `flutter gen-l10n`（本地生成物不提交）。
- 运行 `flutter analyze`。
- 使用当前 `flutter_js` 包路径加载 QuickJS DLL 后运行完整 `flutter test`。
- 不执行 Windows 或 Android 平台构建；构建交给作者侧。
