# 统一书库与三类历史设计

## 目标

书库作为应用第一页，不再使用顶部“漫画 / 小说”分段器。首页第一栏统一展示漫画、小说和番剧的最近历史，随后分别展示漫画收藏、小说收藏和番剧收藏。番剧历史需要保存到具体集数和播放秒数，并可从历史直接续播。

## 范围

本次包含：

- 删除书库页和历史页顶部的漫画/小说分类切换。
- 首页统一历史，按三类内容的最后更新时间混合倒序。
- 首页分别展示漫画收藏、小说收藏、番剧收藏。
- 番剧详情页增加本地收藏按钮。
- 番剧播放历史保存集数和秒级播放位置。
- 从统一历史删除单条记录或清空全部记录。
- 搜索框同时筛选三个收藏区。

本次不改变漫画、小说现有收藏和历史持久化格式，不迁移旧数据，不自动把播放过的番剧加入收藏，也不把下载记录当作历史记录。

## 数据架构

采用“分开存储、统一投影”：

- 漫画继续由 `LibraryStore` 保存收藏和 `ReadState` 历史。
- 小说继续由 `NovelLibraryStore` 保存收藏和 `NovelReadingProgress` 历史。
- 新增 `AnimeLibraryStore`，独立保存番剧收藏和播放历史。
- 新增只读的统一历史模型，把三个 Store 的记录映射为同一种展示数据，在内存中按 `updatedAt` 倒序排列。

统一历史模型至少包含：

- 内容类型：漫画、小说或番剧。
- 稳定标识：来源 ID 和作品 ID，小说使用现有书库 key。
- 标题和封面。
- 最近进度文案。
- 最后更新时间。
- 对应的打开/续读信息。

统一投影不复制漫画或小说历史，也不另存聚合结果，因此旧记录加载后会直接出现在新首页，不存在双写和迁移失败风险。

## 番剧收藏与历史

`AnimeLibraryStore` 使用独立的 SharedPreferences key 保存：

- 收藏：来源 ID、番剧 ID、标题、封面、收藏时间。
- 历史：来源 ID、番剧 ID、标题、封面、分集 ID、分集名称、分集下标、播放位置秒数、已知总时长秒数、最后更新时间。

播放位置按整秒存储。播放器收到位置变化时只更新内存中的当前秒数，并采用短间隔防抖落盘；暂停、切集、页面退出和应用正常退出时立即刷新当前记录。重复写入同一秒不触发持久化。

切换分集时先保存上一集的最终秒数，再把历史指向新分集并从 0 秒开始。播放完成后保留末尾位置，使历史仍能准确反映已经看完的分集。

## 番剧续播流程

从统一历史点击番剧时：

1. 使用历史中的来源 ID 和番剧 ID 创建对应源。
2. 重新获取当前分集列表，优先按分集 ID 找回原分集；找不到时再使用合法的历史下标。
3. 打开 `AnimePlayerPage`，传入历史播放位置。
4. 播放线路成功打开后执行一次 seek，跳转到记录秒数。
5. 若记录位置已经接近当前媒体末尾，则从 0 秒开始，避免每次进入后立即播放完成。

源不可用、作品被删除或分集解析失败时，保留历史记录并显示可重试错误，不静默删除用户数据。

## 首页布局

书库页保留现有毛玻璃标题栏，移除 `LibraryKindSwitch`。工具栏保留统一搜索、小说导入和推荐刷新动作。

未搜索时内容顺序固定为：

1. 统一历史记录：横向卡片，最多展示最近 12 条，提供进入全部历史的入口。
2. 漫画收藏：沿用现有漫画封面卡和打开逻辑。
3. 小说收藏：沿用现有小说封面与本地/远程可用状态。
4. 番剧收藏：使用番剧封面卡，点击进入番剧详情。
5. 原有漫画推荐和浏览内容。

空收藏区仍显示区块标题和简洁空态，避免用户误以为类型入口消失。历史为空时显示统一历史空态。

搜索时同时按标题筛选三个收藏区，不搜索历史和推荐内容。没有匹配结果时显示统一空态。

## 历史页

历史页移除漫画/小说分段器，直接显示混合列表。每行带内容类型标识和对应进度：

- 漫画：章节名称和页码。
- 小说：章节名称和阅读位置。
- 番剧：分集名称和 `时:分:秒` 或 `分:秒` 播放位置。

单条删除只调用该内容类型对应 Store 的删除方法。一键清空在一次确认后清空漫画、小说和番剧历史；任一清理失败时记录错误，其余类型继续执行。

## 收藏行为

番剧详情页增加与漫画详情一致的收藏按钮。收藏仅保存作品元数据，不要求先播放，也不受历史删除影响。取消收藏不会删除番剧历史；清空历史不会取消收藏。

漫画和小说收藏保持现有语义与存储格式。首页只是重新组织展示，不改变收藏数据所有权。

## 云同步与兼容性

漫画和小说继续沿用现有备份及云同步。番剧收藏和历史先纳入本地备份模型，并使用独立版本字段，为后续服务器同步预留稳定结构；本次不扩展服务器协议。

旧版本没有番剧字段时按空集合加载。损坏的单条番剧记录跳过并保留其他有效记录，修复后的数据重新落盘。

## 测试

聚焦测试必须覆盖：

- 漫画、小说、番剧历史按 `updatedAt` 混合排序。
- 相同更新时间时排序稳定。
- 现有漫画和小说历史无需迁移即可展示。
- 番剧收藏新增、取消、持久化和重载。
- 番剧历史按整秒去重、防抖保存和立即刷新。
- 切集先保存上一集，再创建新分集进度。
- 番剧历史按分集 ID 恢复，并在缺失时回退合法下标。
- 播放器打开线路后 seek 到历史秒数。
- 单条删除只影响目标类型，一键清空覆盖三类历史。
- 书库首页不再显示类型分段器，并按规定顺序显示四个核心区块。

完整 Windows、Android 构建和真机播放器验证继续留到集中验证阶段。
