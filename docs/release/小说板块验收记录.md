# 小说板块验收记录

日期：2026-08-01
分支：`codex/novel-reader`
目标平台：Windows、Android

## 本次范围

- 小说源支持发现、搜索、详情、章节列表和正文读取，漫画源与小说源分别选择和管理。
- 小说书架、阅读历史、阅读进度和下载任务使用独立数据，不与漫画数据混合。
- 在线章节可以加入小说下载队列，失败后重试，并从离线缓存打开。
- 本地支持导入 TXT 与可重排 EPUB，导入后复制到应用私有目录。
- 小说阅读器支持滚动、分页、目录跳转、字号、行距、段距、页边距、主题和屏幕常亮。
- 小说收藏、历史、阅读位置和阅读设置进入备份及云同步。
- 简体中文、繁体中文、英语和日语界面已补齐小说相关文本。

## 云同步和隐私边界

- 在线小说同步收藏、历史、阅读位置和阅读设置。
- 本地小说同步标题、作者、文件指纹、目录身份和阅读位置。
- TXT、EPUB 原文件、章节正文、封面二进制和下载缓存不会上传。
- 其他设备恢复后没有本地原文件时保留元数据与进度，并提示重新导入。
- 重新导入相同指纹的文件后可重新关联原有进度。
- 旧备份没有小说字段时按空小说库处理，不影响原漫画数据。

## 支持边界

- 不提供 TXT 或 EPUB 导出。
- 不自动合并不同小说源的章节列表，用户在详情页手动选择来源。
- 不支持带 DRM 的 EPUB、固定版式 EPUB 或缺少可读 spine 的损坏文件。
- EPUB 中的脚本、iframe、事件属性和危险 URL 会被清理。
- Windows 和 Android 编译已经验证；文件选择、系统安装器和 WebView 的完整交互仍建议作者发布前用 Windows 实机和 Android 真机各做一次烟雾测试。本机当前没有连接 Android 设备，因此本轮没有执行真机安装。
