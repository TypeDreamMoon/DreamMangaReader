## 更新行为覆盖

自动化测试已覆盖以下关键行为：

- 默认使用 Gitee，同版本按用户首选源选择，较高版本优先。
- Gitee 请求失败时回退 GitHub；两个源都失败时不会误报“已是最新版”。
- Windows 只选择 x64 安装器，不选择便携 ZIP。
- Android 按设备 ABI 顺序选择分包，仅在没有兼容分包时回退 universal。
- 支持断点续传 `Range`/206，服务端返回 200 时从头重启下载。
- 下载后校验大小与 SHA-256；损坏文件被删除，不会启动安装器。
- 更新对话框显示来源、进度、取消、重试和手动下载状态。
- 校验阶段取消后不会启动安装器。
